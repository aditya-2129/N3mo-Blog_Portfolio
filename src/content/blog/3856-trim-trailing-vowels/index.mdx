Given a string s, return the string after removing all trailing vowels. A trailing vowel is a vowel that appears at the end of the string. Vowels are 'a', 'e', 'i', 'o', 'u' (both lowercase and uppercase).

- Examples
- Constraints
- [Two Pointer Approach](#two-pointer-approach)
- [Built-in Methods Approach](#built-in-methods-approach)
- [Iterative Approach](#iterative-approach)

## Examples

### Example 1

**Input:**
```text
s = "idea"
```

**Output:**
```text
"id"
```

**Explanation:**
Removing "idea", we obtain the string "id".

### Example 2

**Input:**
```text
s = "day"
```

**Output:**
```text
"day"
```

**Explanation:**
There are no trailing vowels in the string "day".

### Example 3

**Input:**
```text
s = "aeiou"
```

**Output:**
```text
""
```

**Explanation:**
Removing "aeiou", we obtain the string "".

## Constraints

```text
1 <= s.length <= 10⁵
s consists of lowercase and uppercase English letters.
```

## Two Pointer Approach

**Intuition**
Start from the end of the string and move backwards until we find a non-vowel character, then return the substring up to that point.

**Steps**
- Initialize a pointer at the end of the string
- Move the pointer backwards while the current character is a vowel
- Return the substring from the start to the pointer position

**Steps**
- Use regex or built-in string methods to remove trailing vowels
- Return the modified string

## Iterative Approach

**Intuition**
Build the result string by iterating from the end and collecting characters until we hit a non-vowel.

**Steps**
- Start from the end of the string
- Collect characters until we find a non-vowel
- Return the result substring

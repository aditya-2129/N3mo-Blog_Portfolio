A square triple (a,b,c) is a triple where a, b, and c are integers and a² + b² = c².

Given an integer n, return the number of square triples (a,b,c) such that 1 &lt;= a, b, c &lt;= n.

- Examples
- Constraints
- [Brute Force](#brute-force)
- [Optimized Brute Force](#optimized-brute-force)
- [Using Set](#using-set)

## Examples

```text
Input: n = 5
Output: 2
Explanation: The square triples are (3,4,5) and (4,3,5).
```

```text
Input: n = 10
Output: 4
Explanation: The square triples are (3,4,5), (4,3,5), (6,8,10), and (8,6,10).
```

## Constraints

```text
1 <= n <= 250
```

## Brute Force

**Intuition**
Check all possible combinations of (a, b, c) from 1 to n and count those satisfying the Pythagorean theorem.

**Steps**
- Iterate through all values of a from 1 to n
- Iterate through all values of b from 1 to n
- Iterate through all values of c from 1 to n
- If a² + b² = c², increment the count

## Optimized Brute Force

**Intuition**
Instead of iterating through c, compute c² = a² + b² and check if it's a perfect square within range.

**Steps**
- Iterate through all values of a from 1 to n
- Iterate through all values of b from 1 to n
- Calculate c² = a² + b²
- Compute c = √(c²) and verify if c² is a perfect square and c ≤ n

## Using Set

**Intuition**
Precompute all valid squares and use a hash set for O(1) lookup when checking if a² + b² is a valid c².

**Steps**
- Create a set containing all squares from 1² to n²
- Iterate through all values of a from 1 to n
- Iterate through all values of b from 1 to n
- Check if a² + b² exists in the set

> **Topics:** Array, Hash Table, Enumeration

Given a 0-indexed integer array nums, return the number of distinct quadruplets (a, b, c, d) such that:

nums[a] + nums[b] + nums[c] == nums[d], and
a &lt; b &lt; c &lt; d

- Examples
- Constraints
- [Brute Force](#brute-force)
- [Hash Map - Enumerate b from Right](#hash-map-enumerate-b-from-right)
- [Hash Map - Enumerate c from Left](#hash-map-enumerate-c-from-left)

## Examples

```text
Input: nums = [1,2,3,6]
Output: 1
Explanation: The only quadruplet that satisfies the condition is (0, 1, 2, 3) because 1 + 2 + 3 == 6.
```

```text
Input: nums = [3,3,6,4,5]
Output: 0
Explanation: There are no such quadruplets.
```

```text
Input: nums = [1,1,1,3,5]
Output: 4
Explanation: There are 4 quadruplets that satisfy the condition:
- (0, 1, 2, 3): 1 + 1 + 1 == 3
- (0, 1, 3, 4): 1 + 1 + 3 == 5
- (0, 2, 3, 4): 1 + 1 + 3 == 5
- (1, 2, 3, 4): 1 + 1 + 3 == 5
```

## Constraints

```text
4 <= nums.length <= 50
1 <= nums[i] <= 100
```

## Brute Force

**Intuition**
Check all possible quadruplets using four nested loops, verifying if the sum of the first three equals the fourth.

**Steps**
- Iterate through all valid index combinations with a &lt; b &lt; c &lt; d
- Check if nums[a] + nums[b] + nums[c] equals nums[d]
- Count all valid quadruplets found

## Hash Map - Enumerate b from Right

**Intuition**
Rewrite the condition as nums[a] + nums[b] == nums[d] - nums[c]. Iterate b from right to left, maintaining a frequency map of differences nums[d] - nums[c] for pairs (c, d) where c &gt; b.

**Steps**
- Iterate b from n-2 down to 1
- For each b, add all pairs (c=b+1, d>c) to a difference map
- For all a &lt; b, check if nums[a] + nums[b] exists in the map and accumulate counts

## Hash Map - Enumerate c from Left

**Intuition**
Rewrite as nums[a] + nums[b] == nums[d] - nums[c]. Iterate c from left to right, maintaining a frequency map of sums nums[a] + nums[b] for pairs (a, b) where b &lt; c.

**Steps**
- Iterate c from 1 to n-2
- For each c, add all pairs (a, b=c-1) where a &lt; b to a sum map
- For all d &gt; c, check if nums[d] - nums[c] exists in the map and accumulate counts

You are given a binary string s. A substring is balanced if it has an equal number of 0's and 1's, and all the 0's and all the 1's in these substrings are grouped consecutively.

Substrings that are balanced:

- "0101" is not balanced because the 0's and 1's are not grouped consecutively.
- "0011" is balanced because the 0's and 1's are grouped consecutively, and their count is equal.
- "0110" is not balanced because the 0's and 1's are not grouped consecutively.

Return the length of the longest balanced substring of s.

- Examples
- Constraints
- [Brute Force](#brute-force)
- [Linear Scan](#linear-scan)

## Examples

### Example 1:
```text
Input: s = "01000111"
Output: 6
Explanation: "000111" is the longest balanced substring with equal number of 0's and 1's and grouped consecutively.
```

### Example 2:
```text
Input: s = "00111"
Output: 4
Explanation: "0011" is the longest balanced substring.
```

### Example 3:
```text
Input: s = "111"
Output: 0
```

## Constraints

```text
1 <= s.length <= 100
s[i] is '0' or '1'.
```

## Brute Force

**Intuition**
We can check every possible substring of the binary string to see if it is balanced. A substring is balanced if it consists of some number of 0s followed by the same number of 1s.

**Steps**
- Iterate through all possible starting indices of the substring.
- For each starting index, iterate through all possible ending indices.
- For each substring defined by the start and end indices, check if it is balanced:
    - It must start with 0s.
    - Once a 1 is encountered, no 0s can follow.
    - The count of 0s must equal the count of 1s.
- Keep track of the maximum length found.

## Linear Scan

**Intuition**
We only need to track consecutive groups of 0s followed by 1s. As we iterate through the string, we count consecutive 0s. When we encounter a 1, we start counting consecutive 1s. The length of the balanced substring formed by these groups is limited by the smaller count (2 * min(zeros, ones)). If we encounter a 0 after counting 1s, the previous pattern is broken, so we reset our counters.

**Steps**
- Initialize `zeros` and `ones` counters to 0, and `res` to 0.
- Iterate through each character in the string:
    - If the character is '0':
        - If we were previously counting 1s (`ones &gt; 0`), it means the pattern "0...1...0" occurred. Reset `zeros` and `ones` to 0.
        - Increment `zeros`.
    - If the character is '1':
        - Increment `ones`.
    - If `zeros &gt;= ones`, we have a valid balanced prefix of the current segment. Update `res` with `2 * ones`.
- Return `res`.

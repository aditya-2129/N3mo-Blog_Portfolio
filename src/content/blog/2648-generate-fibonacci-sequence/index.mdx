Write a generator function that yields the Fibonacci sequence. The Fibonacci sequence is defined as follows: F(0) = 0, F(1) = 1, and F(n) = F(n-1) + F(n-2) for n &gt; 1. The generator should yield 0, 1, 1, 2, 3, 5, 8, ... indefinitely.

- Constraints

- [Iterative Approach](#iterative-approach)
- [Recursive Approach](#recursive-approach)

## Examples

### Example 1
```text
Input: gen = fib_generator()
Output: [0, 1, 1, 2, 3]
Explanation:
gen.next() returns 0
gen.next() returns 1
gen.next() returns 1
gen.next() returns 2
gen.next() returns 3
```

### Example 2
```text
Input: gen = fib_generator()
Output: [0, 1, 1, 2, 3, 5, 8, 13]
Explanation:
gen.next() returns 0
gen.next() returns 1
gen.next() returns 1
gen.next() returns 2
gen.next() returns 3
gen.next() returns 5
gen.next() returns 8
gen.next() returns 13
```

## Constraints

```text
0 <= n <= 10⁴
```

## Generator Approach

**Intuition**
Use the built-in generator/yield functionality to lazily compute Fibonacci numbers one at a time.

**Steps**
- Initialize two variables a = 0 and b = 1
- In an infinite loop, yield a and then update a, b = b, a + b

**Intuition**
Maintain state between calls and compute the next Fibonacci number iteratively.

**Steps**
- Initialize two variables a = 0 and b = 1 in the constructor
- In the next() method, return a and then update a, b = b, a + b

## Recursive Approach

**Intuition**
Use recursion to compute Fibonacci numbers, with memoization to avoid redundant calculations.

**Steps**
- Use memoization to store computed Fibonacci numbers
- For each call to next(), compute the next Fibonacci number using recursion

        if n not in self.memo:

        return self.memo[n]
    
    def next(self):
        result = self.fib(self.n)
        self.n += 1
        return result` },

You are given an integer array nums and an integer k. Return the smallest positive integer x such that x is a multiple of k and x is not present in nums.

- Examples
- Constraints
- [Brute Force](#brute-force)
- [Hash Set](#hash-set)
- [Sorting](#sorting)

## Examples

### Example 1

**Input:**
```text
nums = [8,2,3,4,6], k = 2
```

**Output:**
```text
10
```

**Explanation:**
The multiples of k = 2 are 2, 4, 6, 8, 10, 12... and the smallest multiple missing from nums is 10.

### Example 2

**Input:**
```text
nums = [1,4,7,10,15], k = 5
```

**Output:**
```text
5
```

**Explanation:**
The multiples of k = 5 are 5, 10, 15, 20... and the smallest multiple missing from nums is 5.

## Constraints

```text
1 <= nums.length <= 10⁵
1 <= nums[i] <= 10⁹
1 <= k <= 10⁹
```

## Brute Force

**Intuition**
Iterate through the multiples of k starting from k. For each multiple, check if it exists in the array by scanning the entire array.

**Steps**
- Initialize x = k.
- Loop while true:
  - Check if x exists in nums.
  - If not, return x.
  - Increment x by k.

## Hash Set

**Intuition**
Store the elements of nums in a hash set to allow O(1) lookups. Then iterate through multiples of k and check for existence in the set.

**Steps**
- Create a set from nums.
- Initialize x = k.
- Loop while true:
  - If x is not in the set, return x.
  - Increment x by k.

## Sorting

**Intuition**
Sort the array first. Then iterate through multiples of k and use binary search to check if the multiple exists in the sorted array.

**Steps**
- Sort nums.
- Initialize x = k.
- Loop while true:
  - Perform binary search for x in nums.
  - If not found, return x.
  - Increment x by k.

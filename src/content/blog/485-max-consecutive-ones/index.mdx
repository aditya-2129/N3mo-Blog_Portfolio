## Examples

### Example 1
```text
Input: nums = [1,1,0,1,1,1]
Output: 3
Explanation: The first two digits or the last three digits are consecutive 1s. The maximum number of consecutive 1s is 3.
```

### Example 2
```text
Input: nums = [1,0,1,1,0,1]
Output: 2
```

## Constraints
```text
1 <= nums.length <= 10^5
nums[i] is either 0 or 1.
```

## Single Pass

**Intuition**
Iterate through the array once, keeping track of the current streak of consecutive 1s and the maximum streak seen so far.

**Steps**
- Initialize current count and max count to 0
- Iterate through each element in the array
- If the element is 1, increment current count
- If the element is 0, reset current count to 0
- Update max count with the maximum of max count and current count
- Return max count

## Sliding Window

**Intuition**
Use a sliding window approach where we maintain a window containing only 1s and track the maximum window size.

**Steps**
- Initialize left pointer and max count to 0
- Iterate through the array with right pointer
- If we encounter a 0, move left pointer to right + 1
- Update max count with the maximum of max count and window size (right - left + 1)
- Return max count

## Group By

**Intuition**
Group consecutive 1s together and find the maximum group size.

**Steps**
- Initialize max count to 0
- Iterate through the array
- When we find a 1, count consecutive 1s until we hit a 0
- Update max count with the maximum of max count and current group size
- Return max count

    def findMaxConsecutiveOnes(self, nums: List[int]) -> int:
        max_count = 0
        i = 0
        n = len(nums)
        
        while i &lt; n:
            if nums[i] == 1:
                count = 0
                while i &lt; n and nums[i] == 1:
                    count += 1
                    i += 1
                max_count = max(max_count, count)
            else:
                i += 1
        
        return max_count` },

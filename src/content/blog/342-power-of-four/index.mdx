Given an integer n, return true if it is a power of four, otherwise return false.

An integer n is a power of four, if there exists an integer x such that n == 4x.

- Constraints

## Examples

```text
Input: n = 16
Output: true
Explanation: 24 = 16
```

```text
Input: n = 5
Output: false
```

```text
Input: n = 1
Output: true
```

## Constraints

```text
- -2^31 <= n <= 2^31 - 1
```

## Iterative Division

**Intuition**
Continuously divide n by 4 until it's no longer divisible. If we reach 1, n was a power of 4.

**Steps**
- Handle edge case where n &lt;= 0
- While n is divisible by 4, divide it by 4
- Check if the final result equals 1

## Mathematical Logarithm

**Intuition**
If n is a power of 4, then log₄(n) must be an integer. We can check this using logarithms.

**Steps**
- Handle edge case where n &lt;= 0
- Calculate log base 4 of n
- Check if the result is close to an integer (accounting for floating point precision)

## Bit Manipulation - Power of 2 + Odd Position

**Intuition**
A power of 4 is also a power of 2 (exactly one bit set), but the single bit must be at an even position (0, 2, 4, 6, ...). The mask 0x55555555 has bits set at all even positions.

**Steps**
- Check n &gt; 0
- Check if n is a power of 2 using n & (n-1) == 0
- Check if the single bit is at an even position using n & 0x55555555 != 0

## Bit Manipulation - Modulo 3

**Intuition**
All powers of 4 are congruent to 1 modulo 3. Combined with the power of 2 check, this uniquely identifies powers of 4.

**Steps**
- Check n &gt; 0
- Check if n is a power of 2 using n & (n-1) == 0
- Check if n % 3 == 1

## Recursion

**Intuition**
Recursively check if n/4 is a power of 4, with base cases for n &lt;= 0, n == 1, and n not divisible by 4.

**Steps**
- Return false if n &lt;= 0
- Return true if n == 1
- Return false if n is not divisible by 4
- Recursively call with n/4

## Problem Description

DataFrame students
```
+-------------+--------+
| Column Name | Type   |
+-------------+--------+
| student_id  | int    |
| name        | object |
| age         | int    |
+-------------+--------+
```

Write a solution to rename the columns as follows:
- student_id → Student Id
- name → Name
- age → Age

The output should look like this:
```
+------------+--------+
| Student Id | Name   | Age   |
+------------+--------+
| 1          | Alice  | 20    |
| 2          | Bob    | 21    |
+------------+--------+
```

## Constraints

```text
- 1 <= number of columns <= 100
- 1 <= number of rows <= 1000
- Column names consist of lowercase letters and underscores only
- Column names start and end with a letter (not underscore)
- No consecutive underscores in column names
```

## String Manipulation Approach

**Intuition**
Split each column name by underscores, capitalize each word, and join them back with spaces.

**Steps**
- Get the list of column names from the DataFrame
- For each column name, split by underscore
- Capitalize the first letter of each word
- Join the words with spaces
- Assign the new column names to the DataFrame

def renameColumns(students: pd.DataFrame) -> pd.DataFrame:

    return students` },

**Intuition**
Use list comprehension to transform all column names in a single line of code.

**Steps**

- Apply transformation using list comprehension
- Assign the result back to DataFrame columns

## Regex Approach

**Intuition**
Use regular expressions to find and replace patterns in column names.

**Steps**
- Use regex to find underscores followed by lowercase letters
- Replace with space and uppercase letter
- Capitalize the first letter of the column name

{ name: "Java", lang: "java", code: `import java.util.*;
import java.util.regex.*;

public class Solution {
    public List<List<String>&gt; renameColumns(List<List<String>&gt; students, List<String> columns) {
        List<String> newColumns = new ArrayList&lt;&gt;();
        Pattern pattern = Pattern.compile("_([a-z])");
        
        for (String col : columns) {
            Matcher matcher = pattern.matcher(col);
            StringBuffer sb = new StringBuffer();
            while (matcher.find()) {
                matcher.appendReplacement(sb, " " + matcher.group(1).toUpperCase());
            }
            matcher.appendTail(sb);
            
            String newCol = sb.toString();
            if (!newCol.isEmpty()) {
                newCol = Character.toUpperCase(newCol.charAt(0)) + newCol.substring(1);
            }
            newColumns.add(newCol);
        }
        return students;
    }
}` },

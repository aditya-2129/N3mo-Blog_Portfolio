Given a text file file.txt that contains list of phone numbers (one per line), print all valid phone numbers.

A valid phone number takes one of two formats:
1. (xxx) xxx-xxxx
2. xxx-xxx-xxxx

where x is a digit.

## Examples

### Example 1
Input:
```text
987-123-4567
123 456 7890
(123) 456-7890
```
Output:
```text
987-123-4567
(123) 456-7890
```

### Example 2
Input:
```text
-- 1-293-489-4859
(02) 3456-7890
(123) 456-7890
```
Output:
```text
(123) 456-7890
```

## Constraints
```text
There may be empty lines in the text file.
```

- [Approach 2: Awk with Pattern Matching](#awk-with-pattern-matching)
- [Approach 3: Sed with Substitution](#sed-with-substitution)

## Grep with Regular Expression

**Intuition**
Use grep with a regular expression to match lines that follow either of the two valid phone number formats.

- Define the pattern for valid phone numbers

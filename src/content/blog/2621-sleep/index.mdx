## Examples

### Example 1
```text
Input: millis = 100
Output: 100
Explanation: It should return a promise that resolves after 100ms. 
let t = Date.now(); 
sleep(100).then(() => console.log(Date.now() - t)); // 100
```

### Example 2
```text
Input: millis = 200
Output: 200
Explanation: It should return a promise that resolves after 200ms.
```

## Constraints

```text
1 <= millis <= 1000
```

## Approach 1: Promise with setTimeout

**Intuition**
Use the Promise constructor with setTimeout to create a delay that resolves after the specified time.

**Steps**
- Create a new Promise
- Use setTimeout to resolve the promise after millis milliseconds
- Return the promise

    await asyncio.sleep(millis / 1000)` },

    public void sleep(int millis) throws InterruptedException {
        Thread.sleep(millis);
    }
}` },
{ name: "C++", lang: "cpp", code: `#include <thread>
#include <chrono>

class Solution {
public:
    void sleep(int millis) {
        std::this_thread::sleep_for(std::chrono::milliseconds(millis));
    }
};` },
{ name: "JavaScript", lang: "javascript", code: `async function sleep(millis) {
    return new Promise(resolve =&gt; setTimeout(resolve, millis));
}` },
{ name: "TypeScript", lang: "typescript", code: `async function sleep(millis: number): Promise<void> {
    return new Promise(resolve =&gt; setTimeout(resolve, millis));
}` },]} />

**Complexity**
- Time: O(millis) where millis is the sleep time
- Space: O(1)
- Notes: This is the standard way to implement sleep in JavaScript/TypeScript

## Approach 2: Async/Await Pattern

**Intuition**
Use async/await syntax to wait for the Promise to resolve before continuing.

**Steps**
- Define an async function
- Create a Promise with setTimeout
- Await the Promise to ensure the delay
- Return nothing (void)

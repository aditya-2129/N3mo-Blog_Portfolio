Given an array of integers nums, a pair (i, j) is called good if nums[i] == nums[j] and i &lt; j.

Return the number of good pairs.

- Examples
- Constraints
- [Brute Force](#brute-force)
- [Hash Map Counting](#hash-map-counting)
- [Mathematical Formula](#mathematical-formula)

## Examples

```text
Input: nums = [1,2,3,1,1,3]
Output: 4
Explanation: There are 4 good pairs (0,3), (0,4), (3,4), (2,5) 0-indexed.
```

```text
Input: nums = [1,1,1,1]
Output: 6
Explanation: Each pair (i,j) with i < j is a good pair.
```

```text
Input: nums = [1,2,3]
Output: 0
```

## Constraints

```text
1 <= nums.length <= 100
1 <= nums[i] <= 100
```

## Brute Force

**Intuition**
Check every possible pair of indices and count those where values match and the first index is smaller.

**Steps**
- Initialize count to 0
- Use nested loops to compare each element with all elements after it
- Increment count when values match

## Hash Map Counting

**Intuition**
Track the frequency of each number seen so far. Each time we encounter a number, it forms good pairs with all previous occurrences of that number.

**Steps**
- Create a hash map to store frequency of each number
- For each number in the array, add its current frequency to the count
- Increment the frequency in the map

<CodeTabs client:load tabs={[{ name: "Python3", lang: "python", code: `class Solution:

        count = 0
        freq = {}
        for num in nums:
            if num in freq:
                count += freq[num]
                freq[num] += 1
            else:
                freq[num] = 1
        return count
` },

## Mathematical Formula

**Intuition**
If a number appears k times, it contributes k*(k-1)/2 good pairs (combination formula C(k,2)). Sum this for all unique numbers.

**Steps**
- Count frequency of each number using a hash map
- For each frequency value, compute pairs using formula k*(k-1)/2
- Sum all pairs to get the total

<CodeTabs client:load tabs={[{ name: "Python3", lang: "python", code: `class Solution:

        freq = Counter(nums)
        count = 0
        for v in freq.values():
            count += v * (v - 1) // 2
        return count
` },

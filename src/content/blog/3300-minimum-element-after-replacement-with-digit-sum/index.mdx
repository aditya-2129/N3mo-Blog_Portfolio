You are given an integer array nums.

In one operation, you can replace any element nums[i] with the sum of its digits.

Return the minimum element of nums after performing the operation on each element.

- Examples
- Constraints
- [Iterative Digit Sum](#iterative-digit-sum)
- [String Conversion](#string-conversion)
- [Functional/Stream Approach](#functionalstream-approach)

## Examples

```text
Input: nums = [10,12,13,14]
Output: 1
Explanation:
- 10 becomes 1 + 0 = 1
- 12 becomes 1 + 2 = 3
- 13 becomes 1 + 3 = 4
- 14 becomes 1 + 4 = 5
The minimum element is 1.
```

```text
Input: nums = [1,2,3,4]
Output: 1
Explanation:
- 1 becomes 1
- 2 becomes 2
- 3 becomes 3
- 4 becomes 4
The minimum element is 1.
```

```text
Input: nums = [999,19,199]
Output: 10
Explanation:
- 999 becomes 9 + 9 + 9 = 27
- 19 becomes 1 + 9 = 10
- 199 becomes 1 + 9 + 9 = 19
The minimum element is 10.
```

## Constraints

```text
1 <= nums.length <= 100
1 <= nums[i] <= 10^9
```

## Iterative Digit Sum

**Intuition**
For each number, extract digits using modulo and division operations, sum them up, and track the minimum across all elements.

**Steps**
- Initialize minimum value to infinity
- For each number in the array:
  - Calculate sum of digits by repeatedly taking modulo 10 and dividing by 10
  - Update minimum if current sum is smaller
- Return the minimum value found

## String Conversion

**Intuition**
Convert each number to a string, iterate through characters to extract digits, sum them, and find the minimum.

**Steps**
- Initialize minimum value to infinity
- For each number in the array:
  - Convert number to string
  - Iterate through each character and convert back to digit
  - Sum all digits and update minimum
- Return the minimum value found

## Functional/Stream Approach

**Intuition**
Use functional programming constructs like map, reduce, and streams to transform the array and find the minimum in a declarative style.

**Steps**
- Define a digit sum helper function
- Map each element to its digit sum
- Find the minimum of the transformed values
- Return the result

> **Topics:** Array, Hash Table, Math, Simulation

You are given a positive integer n, that is initially placed on a board. You will perform the following operation exactly n - 1 times:

- If the number x on the board is greater than 1, replace it with x - 1.

Return the number of distinct numbers that will be on the board after performing all operations.

- Examples
- Constraints
- [Approach 1: Simulation with Set](#simulation-with-set)
- [Approach 2: Mathematical Formula](#mathematical-formula)

## Examples

Example 1:
```text
Input: n = 5
Output: 5
```

Example 2:
```text
Input: n = 0
Output: 1
```

## Constraints

```text
0 <= n <= 10⁵
```

## Approach 1: Simulation with Set

**Intuition**
Simulate the process by iterating from n down to 1 and collecting all numbers in a set to count distinct values.

**Steps**
- Initialize an empty set to store distinct numbers
- Iterate from n down to 1
- Add each number to the set
- Return the size of the set

## Approach 2: Mathematical Formula

**Intuition**
Observe that the process generates all integers from 1 to n, so the answer is simply max(1, n).

**Steps**
- Return max(1, n) directly
